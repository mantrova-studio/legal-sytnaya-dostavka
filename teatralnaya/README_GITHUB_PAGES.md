# Информация для потребителей — GitHub Pages

Это полностью статический сайт: HTML + CSS + JS, без сборки и зависимостей.

## Перед публикацией ОБЯЗАТЕЛЬНО

Откройте `site-config.js` и замените значение `hours` на фактический режим работы этой точки. Например:

```js
hours: "Ежедневно, 10:00–23:00",
```

Остальные реквизиты уже заполнены.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий GitHub.
2. Загрузите **содержимое папки сайта** в корень репозитория (`index.html`, `site-config.js`, папку `assets`).
3. Откройте **Settings → Pages**.
4. В `Build and deployment` выберите **Deploy from a branch**.
5. Branch: `main`, Folder: `/(root)`, нажмите **Save**.
6. После публикации GitHub покажет адрес вида `https://username.github.io/repository/`. Именно этот адрес используйте для QR-кода соответствующей точки.

## Свой домен

В Settings → Pages можно указать Custom domain. После настройки DNS GitHub Pages автоматически обслужит сайт по вашему домену.

## Структура

- `index.html` — страница
- `site-config.js` — адрес и режим работы точки
- `assets/styles.css` — оформление
- `assets/app.js` — подстановка параметров точки
- `assets/*.svg` — локальные иллюстрации; внешние картинки не загружаются

## Примечание

Нормативные документы открываются по внешним ссылкам на актуальные тексты. Это уменьшает риск хранить на сайте устаревшую копию закона.
